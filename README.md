# Bar Mobile — barmobile.it

Landing page statica (HTML/CSS/JS in un unico file, nessuna build necessaria).

## Deploy
Repository collegato direttamente a OVH tramite la funzione Git integrata dell'hosting condiviso, branch `main` (nessuna Actions/build richiesta, il file è già pronto).

Ogni push su `main` viene sincronizzato automaticamente su barmobile.it tramite webhook.
